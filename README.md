Employee Directory and Branch Management API

Project Overview

The Employee Directory and Branch Management API enables efficient management of employees and branches within an organization. It provides endpoints for:

Managing employee records (retrieving, creating, updating, and deleting employees).

Handling branch details (retrieving, creating, updating, and deleting branches).

Securing API access with authentication and environment variables.

Offering detailed API documentation via Swagger UI.

This API is particularly useful for HR teams, system administrators, and developers integrating employee and branch management into their applications.
